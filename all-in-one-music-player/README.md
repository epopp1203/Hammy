# All In One Music Player

A starter in-game music UI for connecting services such as Spotify, Apple Music, YouTube, and YouTube Music.

## Current features
- Stylish adjustable theme UI
- Font size and opacity controls
- Service connection cards
- Playback controls and queue preview

## Next steps
- Add OAuth flow for Spotify and Google
- Add a lightweight backend to securely store refresh tokens
- Wire real playback state from your chosen APIs
